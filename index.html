How to read this, and what it is not

Each coloured cell is the LHASA XGBoost probability that a rainfall-triggered landslide occurs in that ~1 km cell on a day with the slider conditions. It is a model output, not a measured frequency for that hillside, and not a flood forecast. The model saturates near 1 under extreme sliders — that is what the model says, not a claim that a landslide is certain.

Inputs, in model order: Lithology, Slope, PGA, soil moisture (gwetprof), antecedent rain, rain ÷ p99. Static layers are the 30-arcsecond (~1 km) LHASA static files, clipped to 97–106°E, 5.5–20.5°N (1080 × 1800 cells). Dynamic inputs here are scenario sliders, not live IMERG/SMAP data — a live version would still need a daily feed for those three.

Tap or click any cell to see its real terrain values, p99, rain ratio and probability. Drag to pan, pinch or use the +/− control to zoom. On a phone, one finger scrolls the page and two fingers move the map, and the “↓ Sliders below” button over the map jumps to the sliders.

Alignment: the data grid is equirectangular but the basemap is Web Mercator, so the overlay is warped row-by-row to Mercator latitudes before drawing — otherwise it drifts by up to ~80 px at zoom 10 and ~315 px at zoom 12. Colours are discrete ColorBrewer YlOrRd bins (0.10–0.20, 0.20–0.35, 0.35–0.50, 0.50–0.65, 0.65–0.78, 0.78–0.86, 0.86–0.91, 0.91–0.95, 0.95–1.00), finer where wet scenarios cluster, so neighbouring probabilities are actually distinguishable instead of one smooth red wash. The layer sits at 60% opacity by default so basemap labels show through; the opacity slider adjusts it.

Basemap: OpenFreeMap vector positron, © OpenStreetMap contributors, © OpenMapTiles. Model: NASA LHASA v2.1.1, XGBoost, 300 depth-2 trees, binary logistic, base score 0.1246 (used as logit). Converted to a 45 KB stripped JSON; traversal verified against the real XGBoost Booster in Python (max difference < 4×10−7). Static data: LHASA static.zip (Slope, Lithology, PGA, mask, p99), 2024-08-07 package. Thailand outline for clipping: GADM v4.1 level 0, simplified to 0.01°. Sources: github.com/nasa/LHASA.
